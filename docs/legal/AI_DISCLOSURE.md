# AI in CSCA Prep

**Status: a draft describing the code as it stands. Not legal advice.**

## Today

There is no AI tutor. The feature flag `AI_TUTOR_ENABLED` is off, no provider
is registered, no key exists anywhere in this repository or its deployment, and
no learner text has ever been sent to a language model by this application.

Nothing in the app is generated by a language model. Every question, solution,
explanation and hint a learner sees was written by a person and is stored in
the content collections. Where a question has not yet been reviewed by a human,
the app says so and does not count it toward readiness.

## If the tutor is turned on

The groundwork exists in `functions/src/tutor/`. This section describes what it
would do, and is the description that must be true before the flag is set for
any real learner.

**What would be sent, and to whom.** A single prompt would go to one language
model provider, from the server, never from the browser. It would contain: the
question's own text and its options, the topic and skill names, the difficulty,
the learner's chosen language, and whatever the learner typed into the tutor
box. It would not contain the learner's name, email, uid, device id, results,
mastery, plan, or any other question.

**What would not be sent, ever, before the learner has answered.** The correct
answer and the worked solution are withheld from the prompt entirely for every
action that runs while the learner is still working. This is not a policy the
model is asked to follow; the values are not in the text it receives.

**What the learner would get back.** Text, screened first. A reply that names
the correct option, quotes the stored solution, announces an answer, or is a
bare option letter is discarded whole and replaced with fixed, human-written
guidance. Replies are labelled by source, so a learner can tell a model's words
from a person's.

**What the tutor could never do.** It cannot grade a diagnostic or a mock,
write a score, change mastery, readiness or the study plan, mark content
verified, publish content, or write to the database. It returns text and
nothing else. During a diagnostic or a mock it refuses every request.

**Limits.** Per-learner hourly quotas, a shared daily budget, and a kill switch
that stops every call.

**Retention.** The application would store an outcome, a reason, a count of
detected prompt-injection patterns, and token counts. It would not store the
prompt, the reply, or the learner's words. What the provider retains is the
provider's own policy and would have to be stated here, accurately, before the
feature is enabled.

## What a learner should know

A language model can be wrong and can be confidently wrong. Anything it says in
this app is a hint about how to think, not a source of truth. The verified
solution, written by a person, is what a learner should trust — and it stays
available whether or not the tutor is on.
